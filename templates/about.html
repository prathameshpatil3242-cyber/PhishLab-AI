What this project is

PhishLab AI is a local web application built for an SY B.Tech Cyber Security coursework project at TKIET Warananagar. It analyses message text and URLs for phishing warning signs, classifies sample messages with a small machine-learning model, and runs safe awareness quizzes using fictional scenarios.

Everything runs on your own computer: Flask serves the pages, SQLite stores the local records, and scikit-learn provides the TF-IDF + Naive Bayes classifier.

Technology stack

Python 3.13+Flask scikit-learnpandas NumPySQLite HTML5 / CSS3 / JSChart.js pytest

Project files

  • app.py — Flask application, all routes and APIs
  • config.py — paths, limits and safe defaults
  • database.py — SQLite init / clear helper
  • analyzer.py — rule-based message analysis (explainable)
  • train_model.py — trains and evaluates the ML model
  • evaluate_model.py — re-scores the saved model on held-out data
  • phishlab/ — the Python package with the logic modules
  • data/sample_messages.csv — fictional labelled dataset
  • templates/, static/ — pages, CSS and JavaScript
  • tests/ — pytest test suite

Ethics and safety rules

  • Only fictional messages, synthetic participants and .test/.example domains are used.
  • No phishing e-mail is ever sent and no credentials are ever collected.
  • Submitted URLs are read as text only — they are never opened or resolved.
  • Submitted message content is never executed or uploaded anywhere.
  • All data stays in a local SQLite file on this computer.
  • No real organisation is impersonated for harmful purposes.
  • No API keys, tokens or personal information are included in the project.

Honest limitations

  • The dataset is small and fictional, so the reported accuracy does not reflect real-world performance.
  • Rule-based scores are heuristics — they are explainable, but they are not probabilities.
  • A result of “no obvious indicators” never proves that a message is safe.
  • Modern phishing can avoid every keyword rule; always verify with the official channel.
